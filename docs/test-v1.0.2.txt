本版内容
----------------------------------------------------------------
1. 🔴 弱网代理清理修复（本次重点）
   Android 8+ 全局 HTTP 代理有**两套键**：别名 http_proxy + 真身
   global_http_proxy_host/port（系统实际读真身）。旧逻辑只认别名，导致：
     · 清理只删掉别名（Deleted 1 rows），真身留着 → 设备继续走死代理；
     · 检测读别名得 null/:0 就判「无残留」→ 直接 return，残留永不清除；
     · 更深一层：ProxyTracker 只在键**变更**时刷新，别名早已不存在时 delete
       不产生通知（Deleted 0 rows），内存里的旧代理继续把**所有流量**
       （含系统联网校验探针）送往已关闭端口
       → 表现为「ping 通、DNS 通，但所有 App 都上不了网」。
   修复后的清理顺序（三步都不能省、不能换）：
     ① settings put global http_proxy :0   ← 触发变更通知刷新 ProxyTracker
     ② 清真身四键（host/port/exclusion_list/pac_url）
     ③ 撤 adb reverse，最后才关本地代理
   新增 readGlobalProxyState / parseGlobalProxyState / isProxyDirty /
   describeProxyState 成套 helper，recoverStaleSession、tickProxy、
   probeDevice、startWeakNet、cleanupStaleProxy 全部改走它们。
2. 修 scripts/run-electron.py 两个静默失效 bug（日志被判「无变化」白等超时；
   relpath 跨盘符抛异常）。
3. README 补「清代理必须 put :0 再清真身」整节。

环境记录（本轮新增经验）
----------------------------------------------------------------
1. ⚠️ **安装目录被卡死进程锁住会让 NSIS 覆盖安装失败**（本例 rc=2，目录被删成残缺态）。
   首次安装失败的原因：旧版 app 实例卡死（无窗口、Not Responding、422MB），
   它锁着 主程序 exe / app.asar / resources\bin\* / resources.pak。
2. ⚠️ **`taskkill` 报「没有此任务的实例在运行」≠ 杀不掉**。旧笔记写的
   「内核句柄泄漏，用户态无解，只有重启」**被本轮实测推翻**：
   ctypes `OpenProcess(0x0001)` + `TerminateProcess` 直接走内核 API，
   一次成功、文件锁立刻全开。当场清掉 3 个被判"只能重启"的僵尸
   （app 33404 / scrcpy 24204 / electron 36124）。
   工具：scripts/_kill-our-processes.py
   注意：绝不按映像名无差别杀 electron.exe（会杀掉 WorkBuddy 自己）；
        scrcpy.exe 必须用路径里的 \resources\bin\ 段匹配（排除同名 QtScrcpy）。
3. ⚠️ **分段验收必须逐段清残留进程**。Stage 3 的 portable 实例若仍存活，
   Stage 4 的 CDP 会连到它（页面 URL 变成 %TEMP% 解压目录），
   表现为 Stage 4 的「页面从安装目录 asar 加载」假失败。
   本轮 Stage 4/5 在清理残留后单独重跑即全绿。
