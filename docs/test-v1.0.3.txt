## 备注

- 设备行由 `<button>` 改 `div[role=button]` 是本次的必要改动：`<button>` 内不能再放按钮，
  否则 HTML 非法且点击事件会被外层吞掉。无障碍语义用 `role` + `tabIndex` + Enter/Space 键处理保留。
- 快速投屏与投屏页共用 `MIRROR_DEFAULTS`；用户在投屏页调过参数后，快投会沿用（localStorage 持久化）。
