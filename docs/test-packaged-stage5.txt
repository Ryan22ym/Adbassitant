生产包验收 · Stage 5：安装版投屏端到端

验证目标：走真实用户路径（启动安装版 → 切投屏页 → 真实点击「启动投屏」）后，
scrcpy 投屏窗口必须真实可见（IsWindowVisible === true），而不是只看进程存活。

修复背景：
  spawnBinary() 曾传 windowsHide:true，导致 scrcpy(SDL2) 继承 STARTF_USESHOWWINDOW+SW_HIDE，
  窗口对象创建成功（HWND/尺寸/位置都对）但 IsWindowVisible 恒为 false，
  屏幕上和任务栏里都看不到。对照实验：windowsHide:false → 3s 内可见；true → 15s+ 不可见。

脚本：scripts/e2e-mirror-installed.cjs   （npm run test:mirror:installed）

脚本缺陷修复（v1.0 验收时发现）：
  原实现调用 scripts/enum-windows.py —— 该文件从未入库，仓库里只有
  enum-windows2.py，而且 v2 用 --exe 传参、不接受位置参数。
  结果窗口枚举恒返回空数组，本段最后两项必然 FAIL（假阴性，非产品问题）。
  已改为调用 enum-windows2.py：它默认按 \resources\bin\scrcpy.exe 结尾精确匹配，
  正好覆盖安装版路径，同时排除同名的 QtScrcpy.exe。
  运行前置：export PYTHON=<托管 python 绝对路径>（本机 shim 下的 python 非托管版本）
