v1.0.18: AAB 拆包签名可配置，修三方登录 Invalid key hash

.aab 本身不含签名，bundletool build-apks 必须重新签一次。以前固定用随包
debug.keystore，应用能装能跑但签名被换掉 —— Facebook/微信/QQ/Google 登录、
推送、地图 key 都按「包名 + 签名」校验，于是报 Invalid key hash。

新增「签名方式」三选一：随包调试密钥库（默认）/ 我的密钥库（保住原签名）/
不签名（仅调试）。选「我的密钥库」可当场测试并一键算出四个平台的 key hash。
签名纳入拆包缓存键，换了签名不会复用旧产物。

顺带修掉三个真实缺陷：
- findKeytool() 依赖裸名 java 路径（dirname('java.exe') == '.'）拼不出 keytool
- spawn ENOENT 的 stderr 自带程序名，宽松判定把没找到的程序误判为可用
- 缺 keytool 时 custom 模式整个判死（签名只靠 bundletool，不该连坐）

主进程/通道/界面全部打通：aab-signing.ts（新）、aab.ts、ipc.ts、preload.ts、
shared/types.ts、ToolsPage 的 SigningPanel、install.css。
