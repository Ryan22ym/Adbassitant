修的坑（四条都是「本地检查全绿、真机才炸」）
1. Electron 把任何 basename 以 .asar 结尾的普通文件当 asar 容器 → 写 app.asar 抛
   Invalid package（纯 Node 无此 shim）→ 暂存时物理名加 .__asar，逻辑名不动
2. manifest 的 electronVersion 不能取 package.json 的区间（^33.3.1 实际是 33.4.11）
   → 改取 node_modules/electron/dist/version
3. 打包后「找不到更新助手脚本」→ 候选路径少算一层（dist-electron/electron/services/
   要往上两层才是 dist-electron/assets/）
4. 🔴 助手被应用的作业对象连坐：应用在带 KILL_ON_JOB_CLOSE 的 job 里
   （LimitFlags=0x3C00），直接 spawn 的助手会被连坐杀掉（能写首行日志、宿主一退
   就没了）；detached:true 则让 PowerShell 退出码 0 但一行都不执行。
   → 改走 `cmd /c start "" /b powershell -File <staging>\update-helper.ps1`，
     并在退出前等助手落下第一行日志（20 秒；等不到就撤销本次更新并删 job.json）。
     脚本落地必须带 UTF-8 BOM（PS 5.1 读无 BOM 的 .ps1 会按 GBK 解，中文注释乱码）
5. 助手脚本 `Start-Process -ArgumentList @()` 抛「参数验证」错（生产里 launchArgs
   恒为空数组）→ 助手恰好死在「启动新版」那一步，catch 把刚换好的文件又还原，
   表现成「更新了一趟、版本没变」。沙箱以前一直给非空 launchArgs，故新增 B6 用例
